ให้ AI วิเคราะห์วิดีโอ Reference

เมื่อได้คลิปที่ชอบแล้ว ให้แนบวิดีโอเข้าไปใน AI แล้วใช้ Prompt ด้านล่างนี้

Prompt นี้จะให้ AI ไล่ดูทั้ง Composition, Camera, Typography, Color, Lighting, Motion, Transition และ Audio ก่อนเปลี่ยนทั้งหมดออกมาเป็น Generation Prompt ที่พร้อมเอาไปใช้สร้างวิดีโอ

AI Motion Graphics Prompt 
You are a motion graphics director and prompt engineer. I’ve uploaded a video (motion graphics / animation / product demo / SaaS explainer). Do this in two phases. Do not skip steps or summarize loosely. Treat this as a professional shot-by-shot breakdown that another creator could rebuild the video from without ever seeing the original.

PHASE 1 — FULL FRAME-BY-FRAME ANALYSIS

Extract and inspect frames across the entire duration (don’t just sample the first few seconds). For each distinct scene/beat, report:

1. Timestamp range (e.g. 0.0–2.5s)
2. Composition & camera — framing, aspect ratio, camera movement (push, pan, orbit, static), depth of field, focal point
3. Subject/content — every object, icon, illustration, photo, or 3D element on screen; its exact shape, style (flat/3D/line/glass/etc.), position, and size relative to frame
4. Text & typography — exact wording, font style/weight (serif, sans, rounded, condensed), size hierarchy, color, letter-spacing, any kinetic animation (fade, slide, mask-reveal, letter-by-letter, blur-in)
5. Color palette — background color(s), foreground/accent colors, note any hex-approximate values, gradients, or monochrome treatment
6. Lighting, shadow & texture — light direction, shadow softness/hardness, surface textures (paper, metal, glass, matte, glossy), grain/noise, vignetting
7. Icons/graphics/UI elements — describe each precisely: shape, line-weight, fill vs. outline, any brand marks, buttons, cursors, progress indicators, chart/data visuals
8. Motion & transitions — how this beat animates in and how it transitions to the next (cut, morph, wipe, dissolve, liquid transition, particle dissolve, match-cut)
9. Audio (if audible/inferable) — music mood/tempo, sound effects (whoosh, click, chime), voiceover presence and tone

Also summarize once at the top:
* Total duration, resolution/aspect ratio, frame rate (if determinable)
* Overall visual style in one line (e.g. “cinematic B&W kinetic typography with metaphor visuals” or “flat glossy SaaS dashboard UI motion”)
* Pacing (cuts per second, energy level)
* Any recurring visual motif or through-line connecting the beats

PHASE 2 — CONVERT THE ANALYSIS INTO AN OMNI FLASH GENERATION PROMPT

Using everything found in Phase 1, write a single, ready-to-paste Google Omni Flash video generation prompt that would recreate this video’s look, pacing, and structure as closely as possible (not a copy of copyrighted specifics; recreate the style and technique, not any protected content).

The prompt must include:
* Style line — one dense sentence covering mood, lighting, color grading, camera behavior, and finish quality (premium/cinematic/glossy/etc.)
* Technical specs — resolution, aspect ratio, fps, duration (match Omni Flash’s native output, currently 10 seconds; if the source is longer, compress the same number of beats proportionally into 10 seconds)
* Beat-by-beat timeline — same structure as Phase 1, rewritten as generation instructions (what appears, how it moves, how it transitions), with exact color values, exact typography description, and exact icon/shape geometry so nothing is left ambiguous
* Typography spec — one line locking the font style so it stays consistent across every text beat
* Sound design line — score mood + key SFX moments, timed to the visual beats
* Final frame spec — describe exactly what the last held frame should look like (this is what viewers remember most)

Format the final prompt as a single copy-paste block, written as direct generation instructions (not questions, not commentary).

PHASE 3 — CUSTOM CHANGE REQUEST

(fill this in before sending, or leave as-is to recreate faithfully)

Apply these swaps/changes to the Phase 2 prompt before finalizing it:
* Brand name / logo: [e.g. “flevo” — attach brand kit image if available]
* Color palette override: [e.g. keep original palette / use these hex codes instead: ___]
* Text/copy override: [replace the on-screen lines with: ___]
* Duration override: [default 10s / specify other]
* Tone/style shift: [e.g. “make it full color instead of B&W” / “make it more playful, less corporate” / no change]
* Anything to remove or add: [e.g. “remove the falling-man metaphor, add a data-chart metaphor instead”]

If a field above is left blank, keep that element faithful to the original video’s analysis.

จุดสำคัญคือ อย่าเปิดแชทใหม่

หลังจาก AI วิเคราะห์วิดีโอเสร็จ เราจะได้ Prompt สำหรับสร้างวิดีโอกลับมา หลายคนอาจคิดว่าต้องก๊อป Prompt ยาวๆ ออกมา แล้วเริ่มนั่งแก้ Scene ทีละจุดเองจริงๆ ไม่จำเป็น

ให้คุยต่อในแชทเดิมเลย

เพราะตอนนี้ AI มีทั้ง Reference Video, ผลวิเคราะห์ Shot, Camera, Composition, Typography, Timing, Transition และ Generation Prompt อยู่ใน Context เดียวกันแล้ว ตรงนี้ทำให้เราสามารถสั่งต่อด้วยภาษาธรรมดามากๆ ได้

Prompt ตัวอย่าง

"เปลี่ยนเรื่องเป็น การใช้ Codex ตัดต่อวิดีโอ
ใช้ Motion Direction และโครงสร้างจาก Reference เดิม
เปลี่ยน Visual, Object และข้อความให้เหมาะกับเรื่องนี้
สร้าง Final Prompt ใหม่พร้อมใช้"

เท่านี้ AI ก็จะนำโครงสร้างเดิมไปตีความใหม่ให้เข้ากับเรื่อง Codex
จากเดิมใน Reference อาจมี Dashboard, Product UI หรือ SaaS Feature ในวิดีโอใหม่อาจเปลี่ยนเป็น Video File, Code Editor, Timeline, Preview และ Rendered Video แต่ Motion Direction เดิมยังสามารถอยู่ต่อได้

ถ้าอยากง่ายกว่านั้น พิมพ์แค่ “เปลี่ยนเรื่องเป็น…”

เมื่อทำไปสักพัก จริงๆ ไม่จำเป็นต้องเขียนยาวทุกครั้งด้วย ถ้า AI เข้าใจ Context จากแชทก่อนหน้าอยู่แล้ว เราสามารถพิมพ์สั้นๆ เช่น

Prompt ตามภาพบนซึ่งได้มาจากการถอดวิเคราะห์วีดีโอต้นฉบับใน ChatGPT

อีกเทคนิค: เอา Prompt ด้านล่างนี้ของมดไปถาม Chat GPT ต่อว่า "ช่วยเปลี่ยนเนื้อหาเป็น .... ใส่เรื่องที่เราต้องการ"

Premium 3D Dental Commercial Prompt 
Use the uploaded REFERENCE VIDEO as the primary motion-design reference.

Create a completely NEW and ORIGINAL premium 3D educational motion-design video explaining the basic concept of clear aligner treatment.

IMPORTANT CREATIVE DIRECTION:
This must feel like a PREMIUM 3D DENTAL COMMERCIAL.
It must NOT look like:
an infographic,
a presentation,
a workflow diagram,
a medical PowerPoint,
a step-by-step instruction card.

The treatment process should be communicated mainly through CINEMATIC 3D TRANSFORMATION.

CORE STORY
Misaligned teeth → 3D scanning → digital movement planning → transparent aligner → multiple aligners progressing visually → gradual positional change → final clear-aligner hero shot
The viewer should understand the concept by WATCHING the teeth and aligners move.
Do not explain every stage with text.

FORMAT
9:16 vertical
10 seconds
Premium medical 3D commercial.
Realistic dental visualization.
Warm minimal studio environment.
Transparent clear-aligner materials.
Smooth cinematic camera movement.
Very little typography.

CRITICAL TYPOGRAPHY RULE
Use ONLY these three Thai text elements in the ENTIRE video:
“จัดฟันใส”
“สแกน 3D”
“ติดตามผล”

NO OTHER TEXT.
Specifically DO NOT DISPLAY:
“ชุดที่ 1”, “ชุดที่ 2”, “ชุดที่ 3”, “ชุดที่ 4”, “ค่อยๆ เคลื่อน”, “วางแผน”, “ขั้นตอน”, “การเคลื่อน”
Do not display aligner numbers.
Do not display arrows with labels.
Do not display a process diagram.
Do not display multiple text labels around the teeth.
Do not create a workflow infographic.
If Thai typography cannot be rendered accurately, remove the text entirely and preserve clean negative space.

0.0–1.5 SEC: HERO INTRO
Start immediately with a beautiful realistic 3D dental arch floating in a warm cream studio environment.
Several teeth have mild natural misalignment.
Use natural ivory enamel.
Soft realistic gums.
Premium studio reflections.
Camera performs a slow cinematic orbit.
Display only: “จัดฟันใส” (Large, elegant Thai typography.)
No additional text.

1.5–3.0 SEC: 3D SCANNING
Camera smoothly pushes toward the teeth.
A thin teal scanning light travels across the entire dental arch.
As the scanning light passes, the realistic teeth temporarily transform into a sophisticated digital mesh.
Show: subtle contour lines, tiny positioning points, soft scanning grid, transparent target outlines.
Display only: “สแกน 3D” (Keep the text small and secondary. The teeth remain the hero.)

3.0–4.5 SEC: VISUALIZE THE PLAN
NO TEXT.
Stay close to the digital dental model.
Show several selected teeth highlighted with subtle teal outlines.
Transparent ghost versions of the teeth appear slightly offset from their current positions.
Use elegant curved trajectory lines to visually indicate intended positional changes.
One tooth subtly rotates. Another shifts slightly sideways. Another moves slightly backward.
Do not complete the movement.
This scene represents treatment planning entirely through motion.
No labels. No arrows containing text. No diagram.
Camera slowly travels around the dental arch.

4.5–6.0 SEC: ALIGNER HERO MOMENT
Transition smoothly back to realistic teeth.
A single transparent clear aligner floats above the dental arch.
Camera moves upward slightly to reveal its shape.
The aligner should look highly realistic: transparent medical plastic, thin polished edges, subtle reflections, realistic refraction, precise dental geometry.
Rotate the aligner slightly in the light.
Then smoothly lower it onto the teeth.
The transparent aligner seats precisely over the dental arch.
Add one satisfying soft transparent click.
NO TEXT.
Make this one of the most visually beautiful moments of the video.

6.0–8.3 SEC: ALIGNER PROGRESSION
THIS SECTION MUST BE VISUAL ONLY.
NO TEXT. NO NUMBERS. NO LABELS. NO “ชุดที่ 1, 2, 3, 4”.
Show the concept of multiple aligners through cinematic object replacement.
Begin with the first transparent aligner seated over the teeth.
It gently lifts upward.
As it lifts, selected teeth make an extremely subtle positional adjustment.
A slightly different transparent aligner smoothly enters from above.
It seats over the teeth.
CUT WITH MOTION.
That aligner lifts.
The teeth make another tiny planned adjustment.
Another aligner replaces it.
Repeat this visually several times.
Use the rhythm: ALIGNER → LIFT → SUBTLE TOOTH MOVEMENT → NEXT ALIGNER → SEAT
Repeat smoothly.
The viewer should intuitively understand: Different aligners guide the teeth through a progression.
Do not explain this using typography.
Use subtle ghosted previous tooth positions for approximately 0.2–0.3 seconds during each movement.
Keep tooth movement realistic and restrained.
NO instant perfect alignment. NO dramatic snapping. NO exaggerated transformation.
Camera gradually moves around the dental arch throughout the sequence so the progression feels cinematic rather than instructional.

8.3–9.2 SEC: PROGRESS VISUALIZATION
NO DIAGRAM. NO WORKFLOW. NO MULTIPLE MINIATURE DENTAL MODELS.
Return to ONE dental arch only.
Camera pulls back slightly.
Briefly show a transparent ghost image of the earlier tooth positions behind the current positions.
The ghost fades away.
This visually communicates progression over time.
Display only: “ติดตามผล” (Small elegant Thai typography. No other text.)

9.2–10.0 SEC: FINAL HERO
The transparent aligner smoothly seats over the dental arch one final time.
Camera performs a premium macro push-in.
A soft teal highlight travels across the edge of the transparent aligner.
The aligner catches the studio light beautifully.
Large Thai headline: “จัดฟันใส”
Nothing else.
Hold on a clean premium dental hero shot.

VISUAL DESIGN
Background: warm cream #F6F2EA
Accent: soft medical teal #58B8AE
Typography: near black #151515
Teeth: natural ivory enamel. Do not create unnaturally white teeth.
Aligner: almost invisible transparent medical plastic with realistic reflections and refraction.
Lighting: premium cosmetic product photography. Large soft key light. Subtle rim light. Soft realistic shadows.

CAMERA
Treat the dental arch like a premium PRODUCT.
Use: slow orbit, macro push-in, controlled perspective shift, smooth tracking movement, subtle pull-back.
Keep the camera continuously moving. Avoid static infographic compositions.

TRANSITIONS
Transitions must happen through OBJECT MOTION.
Examples: scanning light transforms physical teeth into digital mesh, digital mesh dissolves back into realistic teeth, transparent aligner enters from depth, aligner movement motivates the next shot, camera orbit hides cuts, transparent material creates match transitions.
Do NOT transition by replacing one infographic card with another.

SOUND
Premium minimal medical-tech soundtrack.
Use: soft scanning sweep, subtle transparent plastic clicks, gentle cinematic whooshes, very soft digital confirmation sounds.
During the aligner progression: click → movement → click → movement → click
Do not make the sound repetitive or mechanical.

ABSOLUTE NEGATIVE INSTRUCTIONS
DO NOT create a treatment timeline. DO NOT create a flowchart. DO NOT create a circular process diagram. DO NOT create multiple miniature dental images with arrows. DO NOT create numbered aligner stages. DO NOT display “ชุดที่ 1”. DO NOT display “ชุดที่ 2”. DO NOT display “ชุดที่ 3”. DO NOT display “ชุดที่ 4”. DO NOT display “ค่อยๆ เคลื่อน”. DO NOT place explanatory text beside every object. DO NOT turn the final scene into an infographic. DO NOT show instant perfect alignment. DO NOT show guaranteed results. DO NOT show blood, pain, surgery, extraction or graphic anatomy.

FINAL VISUAL PRINCIPLE
SHOW THE PROCESS. DO NOT WRITE THE PROCESS.
The viewer should understand: SCAN → PLAN → ALIGNER → CHANGE ALIGNER → TEETH GRADUALLY CHANGE POSITION → PROGRESS MONITORING through 3D motion alone.
Typography is only a supporting element. The dental objects, transparent aligners, camera movement and transformation must tell the story.
